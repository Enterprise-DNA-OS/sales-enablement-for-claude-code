# Add a read-only view

Read the schema and views.json. Ask which decision the operator needs to make. Add a read-only query using existing data, add the view specification to views.json, then run npm run view. Inspect the resulting HTML and confirm the totals against CLI output. Escape record text through the existing renderer. Do not add write controls, a server or public hosting.
