# weekly-review

Write the Monday enablement review from current records.

Read README.md and docs/compliance.md. Run:

```bash
npm run enablement -- weekly-review  --json
```

Replace placeholders with operator-supplied values. Never pass the literal dots. Names and id prefixes are supported. If ambiguous, show candidates and ask which record. Present the result in plain language. Do not infer evidence, dates, completed work or approval.

Run ramp-review, attention and coaching-queue separately, then weekly-review for the combined evidence and record checks. State overdue work, who owns each next step, and which observations are missing. Do not rank employees or attribute revenue to training. Draft only.
