# Why this desk has no front end

The manager's Monday job is to find late milestones, discuss evidence and agree the next coaching action. A database and a handful of repeatable commands can do that work. Read-only HTML reports make it easy to review or print the result.

A screen also does things this base does not: a mobile learner experience, in-app walkthroughs, course playback, offline capture and drag-and-drop program editing. Salesforce also measures activity inside its own platform. This base records observations supplied by the operator and imports prepared reports. It does not replace those live experiences.

Use this when the work you need is the review desk and its records. Custom screens, integrations and authentication can be scoped with Enterprise DNA. The free code has no per-seat licence fee; database hosting, agent subscriptions and operation still cost money.

The reports are snapshots, not live dashboards. They contain private data and have no login. Keep them local or behind access controls. Claude Code, Codex, OpenCode and Cursor all use the same instructions and CLI.
